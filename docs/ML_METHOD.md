# AstroGuard ML Method

## Purpose

AstroGuard is a simulated, non-diagnostic monitoring prototype. It identifies meaningful changes from an astronaut's personal baseline and provides explainable monitoring signals.

It is not a medical diagnostic system, is not clinically validated, and is not an official NASA system.
