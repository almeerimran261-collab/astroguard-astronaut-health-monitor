# AstroGuard Project Plan

## Challenge

Create health-monitoring software that helps astronauts evaluate and act on their health status during long-duration missions.

## First version

The first version will monitor:

- Sleep
- Fatigue
- Exercise
- Resting heart rate
- Reaction time
- Workload

## System states

The system will classify the situation as:

- Stable
- Watch
- Review Required

## Team roles

- Project lead and NASA research
- Data engineering
- Machine learning
- Dashboard development
- Testing and presentation

## First technical tasks

1. Define the dataset structure.
2. Generate a synthetic astronaut dataset.
3. Calculate personal baselines.
4. Detect unusual trends.
5. Build a Streamlit dashboard.
6. Test the complete workflow.
7. Prepare the final presentation.

## Safety statement

This project uses synthetic or de-identified data. It is a hackathon prototype and must not be used for medical diagnosis or treatment.
